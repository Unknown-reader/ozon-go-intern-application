## Опыт

**ИнфоТеКС · Разработчик C/C++ · 2024 — настоящее время**

SafeBoot — модуль доверенной загрузки и клиент-серверное ПО для управления группой платформ.

- Обмен по прикладному протоколу поверх mTLS.
- Аутентификация по сертификатам с аппаратного токена.
- Многопоточная обработка соединений.
- Юнит-тесты на Google Test, Bash-скрипты сборки, запуск в TeamCity.
- Работа с code review, требованиями и чужим кодом.
